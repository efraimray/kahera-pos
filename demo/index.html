    About this project · v1.0.0 · MIT

    Kahera: a counter-ready POS for Philippine cafés and karinderyas

    Small food businesses often total orders on a calculator and work out Senior and PWD discounts by hand, which is slow and easy to get wrong when VAT is involved. Kahera is a free point-of-sale screen that runs in any browser, works offline, and does the discount math correctly every time.

    Who it is for

    • Cafés, karinderyas, milk-tea stalls and canteens
    • School and cooperative canteens, LGU food courts
    • Pop-up stalls at bazaars and fiestas with one tablet
    • Developers who want a clean vanilla-JS POS to extend

    Features

    • Tap-to-add menu tiles with search, categories and sold-out items
    • Senior/PWD discount pro-rated per diner, with VAT exemption
    • Cash change with quick-bill buttons; e-wallet and card reference numbers
    • Order slip, void with confirmation, shift report and CSV export
    • Menu editor, offline PWA, light and dark themes

    Tech stack

    • Plain HTML, CSS and JavaScript. No framework, no build step
    • money.js: pure functions in integer centavos, unit-tested in Node
    • localStorage with an in-memory fallback
    • Service worker + web manifest for offline use and "Add to Home Screen"

    Install and deploy

    git clone https://github.com/EfraimRay/kahera-pos.git
cd kahera-pos
npm test          # runs the money tests
npx serve .       # or open index.html

    Deploy the folder as-is to GitHub Pages, Netlify, Vercel or Cloudflare Pages. No server or database needed.

    Client pitch

    Offer it as a set-up service: load the client's menu and prices, install it on their tablet as an app, and train the staff in 30 minutes. Add paid extras such as cloud sync across branches, inventory, or a kitchen display, or bundle it with a website.
